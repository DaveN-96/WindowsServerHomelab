# WindowsServerHomelab
Documenting Windows Server Homelab built using Virtualbox

## InitialSetup.md

I install Windows Server through Virtualbox, install Active Directory with my VM as domain controller, and create an Organizational Unit with three users assigned to a Group.

## GroupPolicyManagement.md

I create a GPO for the previously created IT_Department OU, and begin setting Group Policy, focusing on essential security fundamentals like time-bound, password protected screen savers and denying user access to settings.
